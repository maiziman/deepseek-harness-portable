# Agent Note: 独立自定义模型能力 Bundle

Status: implemented

[English](2026-08-28-independent-model-capability-bundle.md) | 中文

## 问题

便携版用户可以连接模型列表未提供思考和图像输入元数据的 OpenAI 兼容端点。修改 DeepSeek Harness 官方包会让这些能力依赖某一个上游构建版本，而根据模型名称猜测会产生错误声明。默认探测公网端点还可能消耗用户额度，或向用户网络之外发送数据。

## 决策

`@maiziman/dsh-model-capabilities` 是安装在上游包旁边、符合 DeepSeek Harness 官方格式的 Bundle。它只观察公开的 `llm-pi-ai` 设置服务和 Credentials 服务，不导入或替换官方适配器。提供方元数据是优先证据；用户在模型或提供方层明确填写的声明始终优先。默认仅允许对准确的 `localhost` 及字面回环、私有网络、链路本地或 IPv6 本地地址执行有上限的主动探测，并拒绝重定向。只有服务器拒绝无效思考等级、且有效请求返回思考字段时才保存思考能力；只有模型对随机排序的两张内嵌私有 PNG 都返回准确的单个颜色词时才保存图像输入能力，解释性或含糊回答会判定失败。

插件会在启动时协调已有本地提供方，并在提供方设置或该路由的凭据引用变化后于后台再次协调。每个进程只会对每组提供方、模型和凭据配置尝试一次，凭据变化时允许重试。设置更新会同步使当前协调代次失效并取消请求，然后在下一个微任务中开始协调，因为官方 SettingsProvider 会在同步更新事件返回后立即提交新的解析值。过期响应会被丢弃；只有当前 revision 写入成功后，探测才会进入本次进程的已尝试记录。插件会抑制自身写入预期 revision 对应的设置通知；如果同一 revision 来自竞争写入，则当前 mutation 失败后会安排重试。提供方层的 `compat` 对象会先合并 base、再合并 user，然后判断显式禁用和思考格式，与官方对普通对象的递归合并一致。如果凭据变化与一次已经受理的异步写入重叠，该轮由插件新增的模型字段会被标记为待确认；下一轮收集新证据时会忽略这些完全相同的新增字段，然后确认它们，或只撤回仍未发生任何改动的新增内容。删除相应提供方或模型会清除待确认条目，日后重新使用同名模型时仍按用户显式配置处理。写入会保留所有无关的提供方和模型字段。插件卸载会取消待处理请求，诊断信息会移除 URL 中的凭据、查询参数和片段。

便携版构建只复制 Bundle 发布的七个文件。首次启动时，桌面启动器会先把这些文件暂存到 Web profile 内，再使用内置的离线 pnpm 运行时和官方 `dsh plugin` 命令登记不含空白字符的相对 `link:` 依赖；插件版本变化后通过现有链接刷新暂存文件。启动器每次都会比较载荷哈希，并在最后复制 `package.json`，因此中断的刷新会在下次启动时重试。链接目标位于 profile 内，能够避开官方 Windows shell 转发绝对路径时的空格歧义。便携目录移动后，启动器会通过同一官方命令执行强制离线安装，根据相对声明重建 pnpm 的绝对 junction。正常启动直接使用该 profile，不再额外传入补丁层。桌面程序会在每个异步启动阶段之间检查是否正在退出，并在活动启动任务及其进程树全部结束后才退出 Electron；成品验证为两个各自最长 120 秒的启动阶段和截图保留了总余量，超时会终止完整进程树。上游 `dsh` 包保持不变。独立用户会从专用的 `plugin-model-capabilities-v*` GitHub Release 获取由相同 7 个文件组成的 npm 压缩包；该 Release 的 Draft、校验和与 Latest 状态都和便携 ZIP Release 分开验证。

## 考虑过的替代方案

- 修改上游适配器会把功能绑定到一份内置构建，并可能在升级时丢失。
- 替换或包装官方提供方条目会重复承担适配器职责，并提高兼容风险。
- 根据提供方名称或模型名称推断能力并不是可靠证据。
- 默认探测所有端点可能消耗额度，并向公共服务发送合成提示。
- 只读取元数据无法识别信息稀疏的本地 OpenAI 兼容服务器。

## 影响

只要便携版启动器继续携带并登记该 Bundle，官方应用升级就可以替换全部上游包而不会移除这项能力。安装后的首次启动会协调已有本地配置。除非用户明确选择 `always` 策略，否则公共端点仍然只读取元数据。移除 Bundle 后，已经保存的能力字段仍是普通用户设置。

如果信息稀疏的本地端点一直不返回肯定证据，应用以后重启时可能再次探测。请求始终在后台执行，具有数量与时间上限，可配置，并且默认限制在本地端点。最终插件压缩包已经通过精确上游标签 `dsh-v0.1.2-alpha.1`（`cd5ef814`）的官方命令完成安装、完整层展开与 Web profile 启动；独立插件 Release 会在公开前按照固定的上游标签和提交重复这项安装验证。后续预发布版本若改变设置服务或 `llm-pi-ai` 数据格式，插件可能需要再次同步更新。
