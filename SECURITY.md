# Security policy

## Supported releases

Only the latest GitHub Release receives packaging and desktop-shell security fixes. DeepSeek Harness, Node.js, Electron, and other dependencies retain their own support policies.

## Report a vulnerability

Do not open a public issue for a vulnerability. Use [GitHub's private security advisory form](https://github.com/maiziman/cedardsh-desktop/security/advisories/new) and include the affected release, reproduction steps, impact, and any suggested mitigation.

Remove API keys, access tokens, credentials, personal data, and private workspace content from every attachment. If a report concerns DeepSeek Harness rather than this repository's packaging or Electron shell, report it to the [upstream project](https://github.com/deepseek-ai/deepseek-harness/security).

You should receive an acknowledgement within seven days. Release timing depends on severity, reproducibility, and whether the fix belongs in this repository or an upstream dependency.
